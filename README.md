# 🛍️ NOVA. — Modern E-Commerce Web Application

**NOVA.** is a modern, responsive e-commerce web application designed for fashion enthusiasts. Built with a clean UI/UX, seamless light/dark theme toggle, interactive filtering, and dynamic shopping features.

---

## ✨ Features

* 🌓 **Dark & Light Mode Toggle:** Seamless theme switching for optimized user experience.
* 🛍️ **Interactive Product Showcase:** Real-time dynamic product listings with categories (Women, Men, Tops, Dresses, Shoes).
* 🔍 **Search & Sort:** Live product search functionality and price sorting (High to Low / Low to High).
* 🛒 **Shopping Cart & Wishlist:** Counter indicators for active cart items and saved favorites.
* 📱 **Fully Responsive:** Optimized layouts across mobile, tablet, and desktop views.
* 💌 **Newsletter Subscription:** Interactive subscription section for brand updates.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 / Modern CSS (Flexbox, CSS Grid)
* **Scripting:** Vanilla JavaScript (ES6+)
* **Icons & Assets:** Custom UI Components & Responsive Layouts
